# Dashboard Information Architecture (IA)

## IA Structure

*   **1.0 Home / Overview**
    *   1.1 Compliance Score & Health Metrics
    *   1.2 Urgent Action Items (Missing Evidence, Expiring Certs)
    *   1.3 AI Systems Summary (Count by Risk Tier)
*   **2.0 AI System Inventory**
    *   2.1 System Details (Purpose, Modality, Vendor)
    *   2.2 Risk Classification Workflow
    *   2.3 Control Gap Analysis
*   **3.0 Evidence Vault**
    *   3.1 Technical Documentation Uploads
    *   3.2 Audit Logs & Quality Management System (QMS) Records
    *   3.3 Third-Party Certifications
*   **4.0 Reporting**
    *   4.1 Technical Documentation (Annex IV)
    *   4.2 Declaration of Conformity (Annex V)
    *   4.3 Transparency Reports
*   **5.0 Settings & Administration**
    *   5.1 User Management & Roles
    *   5.2 Audit Trails
    *   5.3 API Keys & Integrations
