# Compliance Coverage Matrix

This matrix maps EU AI Act requirements to the platform's features.

| EU AI Act Article | Requirement | Platform Feature Coverage |
| :--- | :--- | :--- |
| **Article 6 & Annex III** | Classification of High-Risk AI Systems | Risk Classification Engine maps system purpose to Annex III categories. |
| **Article 9** | Risk Management System | System Inventory module tracks identified risks and mitigation strategies over the lifecycle. |
| **Article 10** | Data and Data Governance | Evidence Vault requires documentation on training data provenance and bias mitigation. |
| **Article 11 & Annex IV**| Technical Documentation | Reporting Module automatically generates Annex IV compliant documentation packages. |
| **Article 14** | Human Oversight | Intake module mandates specification of human-in-the-loop (HITL) mechanisms. |
| **Article 15** | Accuracy, Robustness, Cybersecurity | Evidence Vault stores model evaluation metrics and pentest reports. |
| **Article 17** | Quality Management System (QMS) | Dashboard tracks QMS policy existence and version history. |
| **Article 50** | Transparency Obligations (GenAI) | Intake flags deepfake/GenAI capabilities and enforces watermark documentation. |
